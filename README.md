# 고급유 노트 (Octane95)


고급유와 일반유의 혼합 옥탄가를 계산하고, 차량별 권장 기준과 주유 기록을 함께 관리하는 Flutter 앱입니다.

현재 탱크에 남은 연료를 반영한 최종 옥탄가 계산, 목표 옥탄가에 도달하기 위한 필요 주유량 계산, 기록 기반 통계와 주유비 분석을 제공합니다.

## 주요 기능

### 옥탄가 계산

- **단순 혼합**: 고급유와 일반유의 주유량을 기준으로 평균 옥탄가 계산
- **탱크 기준**: 현재 잔량·현재 옥탄가·추가 주유량·추가 연료 옥탄가를 반영한 최종 옥탄가 계산
- **목표 맞추기**: 원하는 옥탄가에 도달하기 위해 필요한 추가 주유량 계산
- 차량의 권장/경고 옥탄가를 기준으로 계산 결과 상태 표시
- 탱크 용량 대비 충전율과 초과 여부 안내

> 단순 혼합 계산은 고급유 97 RON, 일반유 92 RON을 기준으로 합니다. 계산 결과는 입력값의 부피 가중 평균에 따른 추정치이며 실제 연료 품질과 차량 상태에 따라 차이가 날 수 있습니다.

### 주유 기록과 통계

- 계산 결과를 사용자가 선택하여 로컬 기록으로 저장
- 주유 금액, 단가, 메모 등 선택 입력 지원
- 기록 검색 및 계산 유형별 필터
- 저장 기록 상세 조회·수정·삭제
- 평균·최고·최저 옥탄가와 최근 기록 추세 그래프
- 차량 권장 옥탄가 대비 현재 상태와 기록 간 변화량 표시
- 월간 주유량·주유비·평균 옥탄가 리포트
- 이번 달 지출, 1회 평균 주유비, 지난달 대비 변화 확인

### 차량 관리

- 차량명, 연식, 권장 옥탄가, 경고 기준, 탱크 용량 저장
- 시스템 사진 선택기를 이용한 차량 사진 등록
- 저장된 차량 기준을 계산 결과와 통계에 반영

### 데이터 관리

- 차량 정보와 주유 기록을 JSON 백업 파일로 내보내기
- 백업 파일 검증 및 복구 전 미리보기
- 복구 실패 시 기존 데이터 보호를 위한 롤백 처리
- 기기에 저장된 전체 데이터 삭제

백업 파일에는 차량 사진이 포함되지 않습니다.

## 화면 구성

- **홈**: 최근 옥탄가, 차량 기준, 최근 주유 및 요약 정보
- **기록**: 저장한 주유 기록 검색·필터·관리
- **계산**: 단순 혼합, 탱크 기준, 목표 맞추기
- **통계**: 옥탄가 요약, 추세 그래프, 목표 충족 상태
- **차량**: 차량 프로필과 옥탄가 기준 관리
- **더보기**: 백업·복구, 주유비 관리, 월간 리포트, 도움말 및 문의

## 기술 스택

- Flutter 3.38.10 / Dart
- Material 3
- Hive / SharedPreferences — 로컬 데이터 저장
- fl_chart — 옥탄가 추세 시각화
- Firebase Core / Firebase Analytics — 앱 이용 현황 분석
- image_picker / Android Photo Picker — 차량 사진 선택
- file_picker / path_provider / share_plus — 백업 파일 선택·생성·공유
- in_app_review — 스토어 평가 요청
- Android SDK 36 / JDK 21

## 데이터 및 개인정보

- 차량 정보, 차량 사진, 계산 결과, 주유 기록과 메모는 기본적으로 사용자 기기에 저장됩니다.
- 백업 파일은 사용자가 직접 내보내거나 불러올 때만 시스템 파일 선택기와 공유 기능을 통해 처리됩니다.
- 앱 품질과 사용 흐름을 확인하기 위해 Firebase Analytics로 앱 실행 및 기능 이용 이벤트가 전송될 수 있습니다.
- 차량명, 차량 사진, 메모, 옥탄가 계산값과 같은 사용자의 저장 내용은 분석 이벤트 매개변수로 전송하지 않습니다.
